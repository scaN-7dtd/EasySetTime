# EasySetTime

This mod allows you to move the current game time forward or backward by a specified number of hours and minutes. Unlike the game's "settime" command, which requires you to specify the exact day, hour, and minute you want to set, this mod simply adds or subtracts the specified amount of time from the current game time.
